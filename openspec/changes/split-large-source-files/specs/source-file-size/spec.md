# Spec Delta

## ADDED Requirements

### Requirement: Ограничение размера исходных файлов
**ID:** FR-488

Отслеживаемый исходный файл приложений в `boundaries/` SHALL содержать не больше 300 строк для production-кода и не больше 500 строк для тестов. Сгенерированный код, зависимости, сборка и fixtures MUST исключаться; превышение допускается только записью в `ops/checks/file-size-allowlist.txt` с причиной.

#### Scenario: Новый крупный файл
**ID:** AC-553

- **WHEN** в `boundaries/` добавлен production-файл на 320 строк без записи в allowlist
- **THEN** `make check-file-size` печатает его путь, число строк и порог и завершается с ошибкой

### Requirement: Разбиение не меняет поведение и API
**ID:** FR-489

Разбиение файлов MUST NOT менять поведение, экспортируемые имена и пути импорта, которыми пользуются другие модули, кроме случаев, когда все потребители обновлены в том же изменении. Тесты и линтеры контекста SHALL проходить после разбиения.

#### Scenario: Пакет Go разбит на файлы
**ID:** AC-554

- **WHEN** `orders/slices/order/infrastructure/memory/store.go` разбит на несколько файлов пакета `memory`
- **THEN** экспортируемые имена пакета не изменились, а `go test ./...` и `make lint` в `orders` проходят
