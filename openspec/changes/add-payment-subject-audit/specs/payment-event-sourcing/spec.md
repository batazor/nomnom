# Spec Delta

## ADDED Requirements

### Requirement: Идентификатор пользователя в потоке запечатан
**ID:** FR-760

`PaymentOperationRequested` SHALL хранить идентификатор пользователя только зашифрованным ключом этого пользователя; идентификатор сервиса MUST оставаться открытым. Автор MUST NOT входить в состояние `Payment` и снапшоты, а загрузка `Payment` MUST NOT обращаться к ключам.

#### Scenario: Загрузка после забвения
**ID:** AC-1047

- **GIVEN** ключ автора операции очищен
- **WHEN** `Payment` загружается и выполняется следующая операция
- **THEN** загрузка и операция успешны, события потока не изменены

#### Scenario: Открытый идентификатор в команде
**ID:** AC-1048

- **WHEN** команда запрашивает операцию от пользователя с незашифрованным идентификатором
- **THEN** команда отклоняется, событие не записывается

### Requirement: Ротация KEK не меняет журнал
**ID:** FR-761

Ключи субъектов SHALL оборачиваться старшей настроенной версией KEK, а версия MUST храниться рядом с ключом. Перешифровка MUST менять только `subject_keys`. Поиск ключа пользователя MUST использовать секрет, не зависящий от KEK.

#### Scenario: Перешифровка
**ID:** AC-1049

- **GIVEN** настроены версии 1 и 2, есть ключ версии 1
- **WHEN** выполняется `subjects rewrap`, затем версия 1 удаляется из конфигурации
- **THEN** шифротексты в журнале не изменены, идентификатор открывается, пользователя можно забыть

#### Scenario: Версия KEK не настроена
**ID:** AC-1050

- **WHEN** ключ обёрнут версией, которой нет в конфигурации
- **THEN** чтение ключа завершается ошибкой, а значение не подменяется
