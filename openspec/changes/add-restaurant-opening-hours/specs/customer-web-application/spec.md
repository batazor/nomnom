# Spec Delta

## ADDED Requirements

### Requirement: Владелец редактирует расписание
**ID:** FR-701

Экран управления рестораном SHALL показывать недельное расписание по дням, позволять добавлять и удалять интервалы и сохранять расписание целиком через `setOpeningHours`. Ошибка пересечения SHALL показываться у интервала.

#### Scenario: Сохранение расписания
**ID:** AC-951

- **WHEN** владелец добавляет пятнице интервал 18:00–02:00 и сохраняет
- **THEN** UI отправляет `setOpeningHours` с полным расписанием и показывает сохранённое

### Requirement: Каталог показывает время открытия
**ID:** FR-702

Ресторан, открытый флагом и находящийся вне расписания, SHALL показываться с «Откроется в HH:MM» в поясе ресторана; его меню SHALL быть доступно для просмотра, а оформление заказа MUST быть недоступно.

#### Scenario: Ресторан ещё не открылся
**ID:** AC-952

- **WHEN** покупатель открывает ресторан с `nextOpeningAt` сегодня 10:00
- **THEN** UI показывает «Откроется в 10:00», меню видно, кнопка оформления недоступна
