# Spec Delta

## ADDED Requirements

### Requirement: Метка приоритета на экране заказа
**ID:** FR-654

Экран заказа SHALL показывать метку «Приоритет» и доплату в составе суммы для заказа с `priority = PREMIUM`. Метка MUST NOT обещать срок.

#### Scenario: Премиум-заказ
**ID:** AC-866

- **WHEN** покупатель открывает премиум-заказ
- **THEN** экран показывает метку «Приоритет» и строку доплаты
