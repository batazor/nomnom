# Spec Delta

## ADDED Requirements

### Requirement: Кухня берёт следующий заказ из очереди
**ID:** FR-655

Колонка кухни на флоу-борде SHALL показывать заказы в `QUEUED` в порядке Get Kitchen Queue без действия на карточке и одну кнопку «Взять следующий», которая вызывает `StartNextPreparation` с новым `request_id` на попытку, переиспользуемым при ручном retry. Премиум-карточки SHALL иметь метку «Приоритет». Отказы `NoCookAvailable` и `KitchenQueueEmpty` SHALL показываться локализованным сообщением. Симулятор кухни SHALL вызывать ту же команду.

#### Scenario: Кухня берёт следующий
**ID:** AC-867

- **GIVEN** в очереди обычный заказ и премиум-заказ, поставленный позже
- **WHEN** сотрудник нажимает «Взять следующий»
- **THEN** премиум-заказ переходит в колонку приготовления, обычный остаётся в очереди

#### Scenario: Нет свободного повара
**ID:** AC-868

- **WHEN** сотрудник нажимает «Взять следующий», а свободного Cook нет
- **THEN** колонка показывает сообщение об отсутствии свободного повара, очередь не меняется
