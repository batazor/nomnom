# Spec Delta

## MODIFIED Requirements

### Requirement: Update Restaurant меняет только разрешённые данные
**ID:** FR-202

Система SHALL позволять авторизованному управляющему менять название ресторана с теми же инвариантами, что и при регистрации, а также задавать или убирать доплату за премиум-приоритет. Доплата MUST быть точной суммой больше 0 с валютой ISO 4217. Ресторан без доплаты не предлагает премиум-приоритет. Update Restaurant MUST NOT менять открытость ресторана и MUST NOT публиковать бизнес-факт. Публичное представление ресторана SHALL содержать доплату, если она задана.

#### Scenario: Переименование ресторана
**ID:** AC-205

- **WHEN** управляющий меняет название существующего ресторана
- **THEN** название обновлено, версия ресторана увеличена, открытость не изменилась

#### Scenario: Ресторан не найден
**ID:** AC-206

- **WHEN** запрошено изменение несуществующего ресторана
- **THEN** операция отклоняется как not found

#### Scenario: Ресторан включает премиум-приоритет
**ID:** AC-849

- **WHEN** управляющий задаёт доплату 99.00 RUB
- **THEN** Get Restaurant возвращает доплату 99.00 RUB

#### Scenario: Ресторан убирает премиум-приоритет
**ID:** AC-850

- **WHEN** управляющий убирает доплату
- **THEN** Get Restaurant возвращает ресторан без доплаты

#### Scenario: Некорректная доплата
**ID:** AC-851

- **WHEN** управляющий задаёт доплату 0 или отрицательную
- **THEN** операция отклоняется как некорректный ввод, ресторан не меняется
