# Spec Delta

## MODIFIED Requirements

### Requirement: Register Courier
**ID:** FR-301

Оператор или диспетчер платформы SHALL иметь возможность зарегистрировать `Courier` с заданным идентификатором и именем; новый `Courier` MUST создаваться в состоянии available. Имя MUST быть непустым после trim и не длиннее 64 символов, иначе регистрация отклоняется как некорректный запрос. Повторная регистрация того же идентификатора MUST отклоняться как already exists без изменения существующего `Courier`, в том числе выбывшего.

#### Scenario: Регистрация нового курьера
**ID:** AC-302

- **WHEN** оператор регистрирует курьера «Тимур» с ещё не использованным идентификатором
- **THEN** создан `Courier` «Тимур» в состоянии available

#### Scenario: Повторная регистрация
**ID:** AC-303

- **WHEN** оператор регистрирует курьера с уже существующим идентификатором
- **THEN** сценарий отклоняется как already exists, состояние существующего `Courier` не меняется

#### Scenario: Курьер без имени
**ID:** AC-787

- **WHEN** оператор регистрирует курьера с пустым именем
- **THEN** сценарий отклоняется как некорректный запрос, `Courier` не создан
