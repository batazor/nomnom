# Spec Delta

## ADDED Requirements

### Requirement: Колонка запланированных заказов
**ID:** FR-688

Флоу-борд SHALL показывать колонку «Запланированные» между входящими заказами и очередью: заказы из List Scheduled Orders с окном и `planned_ready_at`, без действий на карточке. Входящий запланированный заказ SHALL иметь метку окна. Симулятор кухни SHALL принимать запланированные заказы без собственного срока.

#### Scenario: Заказ уходит в очередь в срок
**ID:** AC-932

- **WHEN** наступает `start_at` запланированного заказа
- **THEN** карточка переходит из колонки «Запланированные» в очередь по subscription, без polling
