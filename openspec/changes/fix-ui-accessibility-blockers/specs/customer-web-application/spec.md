# Spec Delta

## MODIFIED Requirements

### Requirement: Доступный и responsive foundation
**ID:** FR-004

Customer UI SHALL соответствовать WCAG 2.2 уровня AA. Интерактивные элементы SHALL сохранять keyboard navigation, visible focus, semantic labels и screen-reader semantics; базовый shell SHALL быть mobile-first и учитывать `prefers-reduced-motion`. На ширине viewport 320 CSS px каждый экран MUST показывать всё содержимое и все элементы управления без горизонтальной прокрутки и без обрезки.

#### Scenario: Использование shell с клавиатуры на узком экране
**ID:** AC-007

- **WHEN** пользователь открывает placeholder-экран с mobile viewport и перемещается только клавиатурой
- **THEN** содержимое не требует горизонтальной прокрутки, интерактивные элементы доступны в логичном порядке, а фокус видим

#### Scenario: Меню и корзина на ширине 320px
**ID:** AC-1098

- **GIVEN** viewport шириной 320 CSS px и открыт ресторан с позициями в корзине
- **WHEN** пользователь просматривает меню и корзину
- **THEN** кнопки «Добавить», пометки «В корзине» и «Нет в наличии», строки корзины и кнопка оформления целиком видны внутри листа, а страница не прокручивается по горизонтали

## ADDED Requirements

### Requirement: Альтернатива перетаскиванию
**ID:** FR-779

Каждое действие, которое UI позволяет выполнить перетаскиванием, SHALL быть доступно и без него: одним нажатием, в том числе с клавиатуры. Перетаскивание MAY оставаться дополнительным способом.

#### Scenario: Диспетчер предлагает заказ курьеру с клавиатуры
**ID:** AC-1099

- **GIVEN** диспетчер видит пул курьеров, заказ кухни принят, курьер ему не предложен, и в пуле есть свободный курьер «Анна» без предложения
- **WHEN** диспетчер клавиатурой открывает на карточке заказа действие «Предложить курьеру» и выбирает «Анна»
- **THEN** заказ предлагается курьеру «Анна», как при перетаскивании карточки на его строку

#### Scenario: Свободных курьеров нет
**ID:** AC-1100

- **GIVEN** диспетчер видит принятый заказ без курьера, а свободных курьеров без предложения в пуле нет
- **WHEN** диспетчер открывает на карточке заказа действие «Предложить курьеру»
- **THEN** UI сообщает, что свободных курьеров нет, и ничего не отправляет

#### Scenario: Пользователь без пула курьеров
**ID:** AC-1101

- **WHEN** `courierPool` отвечает `PermissionDenied`
- **THEN** на карточках заказов кухни нет действия «Предложить курьеру»

### Requirement: Фокус после действия
**ID:** FR-780

После нажатия на элемент управления фокус MUST NOT переходить на `body`. Пока действие выполняется, фокус SHALL оставаться на нажатом элементе, а повторное нажатие MUST NOT запускать действие ещё раз. Если нажатый элемент исчезает, фокус SHALL переходить на ближайший по смыслу элемент: оставшуюся часть той же карточки, следующую карточку колонки или заголовок колонки.

#### Scenario: Кнопка во время запроса
**ID:** AC-1102

- **WHEN** пользователь клавиатурой нажимает кнопку, запускающую запрос
- **THEN** пока запрос выполняется, фокус остаётся на кнопке, она помечена недоступной для скринридера, а повторное нажатие ничего не отправляет

#### Scenario: Карточка заказа меняет стадию
**ID:** AC-1103

- **WHEN** сотрудник кухни клавиатурой нажимает «Принять» на карточке заказа
- **THEN** после смены стадии фокус находится на заголовке той же карточки

#### Scenario: Карточка уходит из колонки
**ID:** AC-1104

- **GIVEN** в колонке кухни два заказа в `RECEIVED`
- **WHEN** сотрудник клавиатурой отклоняет первый
- **THEN** фокус переходит на заголовок второй карточки; если карточек в колонке не осталось — на заголовок колонки

#### Scenario: Заказ оформлен
**ID:** AC-1105

- **WHEN** покупатель клавиатурой оформляет заказ и корзина пропадает
- **THEN** фокус переходит на появившийся заказ на доске

#### Scenario: Выбор ресторана и возврат к списку
**ID:** AC-1106

- **WHEN** покупатель клавиатурой выбирает ресторан, а затем нажимает «← Все рестораны»
- **THEN** после выбора фокус стоит на заголовке ресторана, а после возврата — на карточке этого ресторана в списке

### Requirement: Язык документа
**ID:** FR-781

Атрибут `lang` корневого элемента документа SHALL совпадать с локалью приложения из runtime config и MUST NOT задаваться фиксированным значением в разметке.

#### Scenario: Английская локаль
**ID:** AC-1107

- **GIVEN** runtime config задаёт локаль `en`
- **WHEN** приложение отрисовано
- **THEN** у `<html>` атрибут `lang="en"`
