# Proposal

## Why

Аудит `boundaries/ui` по WCAG 2.2 (A/AA) нашёл четыре нарушения, при которых задачу нельзя выполнить без мыши, скринридером или на узком экране. Предложить заказ курьеру можно только перетаскиванием. На ширине 320px кнопки меню и «Оформить» уходят за край листа. После почти каждого действия фокус падает на `body`. Язык документа всегда `ru`, даже при локали `en`. Требование FR-004 обещает keyboard navigation и mobile-first, но не задаёт ни уровень соответствия, ни эти случаи, поэтому нарушения не ловятся.

## What Changes

- Целевой уровень доступности customer UI — WCAG 2.2 AA. Reflow без горизонтальной прокрутки на ширине 320 CSS px — проверяемое требование, а не только принцип shell.
- У каждого действия, которое выполняется перетаскиванием, есть альтернатива одним нажатием, доступная с клавиатуры. На флоу-борде диспетчер предлагает заказ кухни свободному курьеру из меню на карточке заказа; перетаскивание остаётся.
- Фокус после действия не теряется. Пока запрос выполняется, фокус остаётся на кнопке. Если нажатый элемент исчезает, фокус переходит на предсказуемое место: следующую карточку колонки, заголовок колонки, новый заказ или заголовок открытого ресторана.
- Атрибут `lang` документа совпадает с локалью приложения из runtime config.

Не входит: остальные нарушения AA из аудита — контраст границ полей и переключателя (1.4.11), закрытие подсказок по Escape (1.4.13), объявление результатов действий (4.1.3), передача смысла только цветом на карте и в прогрессе доставки (1.4.1). Они пойдут отдельным change.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `customer-web-application` — FR-004 задаёт WCAG 2.2 AA и reflow на 320px; новые требования: альтернатива перетаскиванию, сохранение фокуса после действия, язык документа.

## Impact

Только `boundaries/ui`, без изменений GraphQL-схемы и BFF.

- **Примитивы:** `src/shared/ui/button.tsx` и стили кнопок в `src/styles.css`.
- **Флоу-борд:** `src/features/flow-board/` — `kitchen-column.tsx`, `courier-column.tsx`, `courier-pool.tsx`, `flow-board.tsx`.
- **Меню и корзина:** `src/features/view-restaurant/` — `view-restaurant.css`, `cart-bar.tsx`, `menu.tsx`, `cart-panel.tsx`.
- **Оформление и переключатели:** `src/features/place-order/place-order.tsx`, `src/features/demo-simulator/simulator-toggle.tsx`.
- **Язык:** `src/shared/i18n/i18n.tsx`, `index.html`.
- **Документация:** раздел «Accessibility и responsive» в `docs/ui.md`.
