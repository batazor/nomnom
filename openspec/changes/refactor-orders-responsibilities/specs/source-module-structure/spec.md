# Spec Delta

## ADDED Requirements

### Requirement: Единая классификация ошибок orders
**ID:** FR-545

Ошибки use cases `orders` SHALL классифицироваться одной функцией, а адаптеры (gRPC, Kafka consumer, Temporal Activities, метрики) SHALL переводить классы своими таблицами, покрывающими все классы.

#### Scenario: Новая доменная ошибка
**ID:** AC-635

- **WHEN** в домен добавляется ошибка, нарушающая правило перехода
- **THEN** её достаточно отнести к классу в одной функции, и все адаптеры обрабатывают её согласованно

### Requirement: Модель назначения курьера в домене orders
**ID:** FR-546

Правила назначения и снятия курьера SHALL принадлежать доменной модели `orders`; инфраструктура и другие use cases MUST NOT импортировать use case ради этого типа.

#### Scenario: Устаревшее событие назначения
**ID:** AC-636

- **WHEN** приходит событие назначения старше сохранённого
- **THEN** решение «устарело» принимает доменная модель, а use case только сохраняет результат
