# Proposal

## Why

Часть файлов собрала несколько несвязанных ответственностей: в `delivery` `infrastructure/grpc/identity.rs` держит проверку service token, user assertions, загрузку JWKS и большой встроенный модуль тестов; `pkg/config/mod.rs` — все секции конфигурации сразу; `infrastructure/postgres/mod.rs` и `infrastructure/reconcile.rs` — несколько компонентов; в `payments` `infrastructure/messaging/relay.py` совмещает модель Outbox, хранилище, Kafka publisher и метрики, `pkg/config/__init__.py` — все настройки; в `restaurants` `pkg/config/config.ts` — все секции и разбор окружения; в `orders` пакеты `memory`, `postgres` и `domains/order` держат несвязанные операции в одном-двух файлах. Такие файлы трудно читать и ревьюить: чтобы понять одну часть, приходится пролистывать остальные.

## What Changes

- Файлы, в которых смешаны несвязанные ответственности, делятся по смыслу во всех приложениях (`orders`, `payments`, `restaurants`, `delivery`, `bff`, `ui`), без изменения поведения и публичных API:
  - **Go**: пакет делится на файлы по теме (типы и конструкторы, отдельные операции, ошибки, адаптеры), тесты — по тем же темам;
  - **Rust**: крупные встроенные `#[cfg(test)] mod tests` выносятся в `<module>/tests.rs`, `mod.rs` с несколькими компонентами — в подмодули;
  - **TypeScript, Python**: модуль делится на модули по ответственности с прежними экспортами из исходного модуля, если на него ссылаются извне.
- Критерий — связность, а не размер: длинный, но цельный файл (например, таблица переходов FSM или один агрегат) не делится. Порогов по числу строк и автоматической проверки размера нет.
- Файлы, которые меняют параллельные changes `extract-order-fulfillment-slice`, `fix-delivery-slice-boundaries` и `rename-restaurant-order-slice`, делятся после них, в том же исполнении по контексту.

Не входит: изменение поведения, переименование публичных API, рефакторинг логики сверх разбиения.

## Capabilities

### New Capabilities

- `source-module-structure`: модули делятся по ответственности без изменения поведения и API.

### Modified Capabilities

Нет.

## Impact

- Приложения в `boundaries/`.
- Сгенерированный код и внешние контракты не меняются.
