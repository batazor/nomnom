# Spec Delta

## ADDED Requirements

### Requirement: Каждый вид операции имеет явное правило
**ID:** FR-549

Применение результата финансовой операции SHALL определяться явным правилом для каждого `OperationKind` (право, trigger, действие при успехе и при отказе); вид без правила MUST приводить к ошибке, а не к действию другого вида.

#### Scenario: Вид без правила
**ID:** AC-639

- **WHEN** результат операции применяется к виду, для которого нет правила
- **THEN** применение завершается ошибкой, и `Payment` не меняется
