# Spec Delta

## MODIFIED Requirements

### Requirement: Состояние и бизнес-факты фиксируются атомарно
**ID:** FR-414

События потока `Payment`, его проекции и снапшот, регистрация provider message и записи бизнес-фактов для публикации SHALL фиксироваться в одной локальной транзакции. Сбой любой из этих записей MUST откатывать все изменения транзакции. Provider call MUST NOT выполняться внутри локальной транзакции.

#### Scenario: Сбой записи факта
**ID:** AC-432

- **WHEN** запись бизнес-факта для публикации завершается ошибкой после применения результата provider
- **THEN** события потока и проекции `Payment` и `Payment Operation` этой транзакции не фиксируются, а повтор с тем же idempotency key может завершить операцию
