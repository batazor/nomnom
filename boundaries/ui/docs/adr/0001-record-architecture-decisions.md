# 1. Вести архитектурные решения customer UI

Date: 2026-10-28

## Status

Accepted

## Context

Customer UI — отдельная application boundary со своим образом, chart и правилами доставки статики. Ей нужен собственный журнал решений рядом с кодом, не смешанный с общесистемными решениями nomnom.

## Decision

Архитектурные решения, принадлежащие только customer UI, документируются в виде ADR в директории `boundaries/ui/docs/adr`. Для управления локальным журналом используется [adr-tools](https://github.com/npryce/adr-tools).

## Consequences

Решения UI хранятся рядом с boundary и имеют собственную нумерацию. Общесистемные решения по-прежнему фиксируются в корневом журнале `docs/adr`.
