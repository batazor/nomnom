# 1. Вести архитектурные решения контекста orders

Date: 2026-10-24

## Status

Accepted

## Context

Контексту `orders` нужен собственный журнал решений, чтобы его архитектурная история находилась рядом с документацией контекста и не смешивалась с общесистемными решениями nomnom.

## Decision

Архитектурные решения, принадлежащие только контексту `orders`, документируются в виде ADR в директории `boundaries/orders/docs/adr`. Для управления локальным журналом используется [adr-tools](https://github.com/npryce/adr-tools).

## Consequences

Решения `orders` хранятся рядом с контекстом и имеют собственную нумерацию. Общесистемные решения по-прежнему фиксируются в корневом журнале `docs/adr`, поэтому при создании ADR нужно выбрать журнал по области действия решения.
