# Batch Get Menus

## Сценарий

- **Тип:** Query.
- **Actor:** Внутренний actor, собирающий страницу со многими ресторанами (BFF).
- **Намерение:** Получить актуальные меню ресторанов всей страницы одним вызовом.
- **Результат:** Возвращены меню ресторанов из 1..100 id, у которых меню есть; ресторан без меню в результат не попадает.

## Границы

- **Владелец:** `restaurants/slices/menu`.
- **Домен:** `domains/menu`.
- **Взаимодействие:** Читает query model через кеш Get Menu (ADR 43, локальный ADR 3) одним `MGET` и одним запросом промахов. Пакетное чтение вместо вызова на каждый элемент — ADR 7.
