# Set Opening Hours

## Сценарий

- **Тип:** Command.
- **Actor:** Авторизованный управляющий ресторана (`restaurant#manage`).
- **Намерение:** Задать недельное расписание работы ресторана.
- **Результат:** Расписание `Restaurant` заменено целиком; интервалы по дням недели в местном времени ресторана, переход через полночь допустим, пересечения запрещены (FR-696, FR-697).

## Границы

- **Владелец:** `restaurants/slices/restaurant`.
- **Домен:** `domains/restaurant` (`OpeningHours`, `TimeZone`).
- **Взаимодействие:** Проверяет права и применяет инварианты расписания; бизнес-факт не публикуется, кеш каталога обновляется по TTL.

Общий каталог: [Restaurants use cases](../../../../README.md#use-cases).
