# Set Scheduled Order Settings

## Сценарий

- **Тип:** Command.
- **Actor:** Авторизованный управляющий ресторана (`restaurant#manage`).
- **Намерение:** Задать или убрать настройки запланированных заказов: ёмкость окна доставки, отступ первого окна от открытия и допуск последнего окна после закрытия.
- **Результат:** Настройки `Restaurant.scheduledOrders` заданы вместе или убраны (`clear`); без настроек ресторан не берёт запланированные заказы (FR-672). Ёмкость — целое больше 0, отступ и допуск — неотрицательные длительности, иначе `INVALID_ARGUMENT`.

## Границы

- **Владелец:** `restaurants/slices/restaurant`.
- **Домен:** `domains/restaurant` (`ScheduledOrderSettings`).
- **Взаимодействие:** Проверяет права; существующие Slot Reservation не меняются, новые проверяются по новым значениям. Бизнес-факт не публикуется, кеш каталога обновляется по TTL.
