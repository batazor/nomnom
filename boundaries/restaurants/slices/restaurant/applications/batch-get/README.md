# Batch Get Restaurants

## Сценарий

- **Тип:** Query.
- **Actor:** Внутренний actor, собирающий страницу со многими ресторанами (BFF).
- **Намерение:** Получить публичные данные ресторанов всей страницы одним вызовом.
- **Результат:** Возвращены найденные рестораны из 1..100 id; неизвестный id в результат не попадает.

## Границы

- **Владелец:** `restaurants/slices/restaurant`.
- **Домен:** `domains/restaurant`.
- **Взаимодействие:** Читает query model через кеш чтения каталога (ADR 43, локальный ADR 3) одним `MGET` и одним запросом промахов. Пакетное чтение вместо вызова на каждый элемент — ADR 7.
