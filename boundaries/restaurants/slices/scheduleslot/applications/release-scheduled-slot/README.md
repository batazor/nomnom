# Release Scheduled Slot

## Сценарий

- **Тип:** Command.
- **Actor:** `service` identity процесса `orders` (компенсация workflow: отказ оплаты, отмена, неудача после резервации).
- **Намерение:** Освободить место заказа в окне.
- **Результат:** Резервация заказа удалена; отсутствующая резервация — успешный no-op, окно не меняется (FR-675).

## Границы

- **Владелец:** `restaurants/slices/scheduleslot`.
- **Домен:** `domains/scheduleslot` (`ScheduleSlot`).
- **Взаимодействие:** Окно находится по `order_id`; конкурентная запись повторяется. Бизнес-факт не публикуется.
