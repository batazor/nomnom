# 1. Вести архитектурные решения контекста restaurants

Date: 2026-10-25

## Status

Accepted

## Context

Контексту `restaurants` нужен собственный журнал решений, чтобы его архитектурная история находилась рядом с документацией контекста и не смешивалась с общесистемными решениями nomnom.

## Decision

Архитектурные решения, принадлежащие только контексту `restaurants`, документируются в виде ADR в директории `boundaries/restaurants/docs/adr`. Для управления локальным журналом используется [adr-tools](https://github.com/npryce/adr-tools).

## Consequences

Решения `restaurants` хранятся рядом с контекстом и имеют собственную нумерацию. Общесистемные решения по-прежнему фиксируются в корневом журнале `docs/adr`, поэтому при создании ADR нужно выбрать журнал по области действия решения.
