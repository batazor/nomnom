# Agent instructions

## Agent skills

### Issue tracker

Задачи ведутся в Linear workspace `bestnomnom`; проект выбирается по области задачи. См. `docs/agents/issue-tracker.md`.

### Triage labels

Используются стандартные labels Matt Pocock skills. См. `docs/agents/triage-labels.md`.

### Domain docs

Используется multi-context layout с общесистемными и контекстными ADR. См. `docs/agents/domain.md`.

## Порядок работы

Сначала внести все изменения задачи целиком, проверять (деплой, прогоны, тесты) — один раз в конце.
Не применять и не проверять каждый шаг по отдельности по ходу работы.
