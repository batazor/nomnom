# Domain Docs

Репозиторий использует multi-context layout.

## Перед исследованием

- Прочитать `GLOSSARY-MAP.md`, если он существует.
- Прочитать `GLOSSARY.md` затрагиваемых bounded contexts.
- Проверить общесистемные ADR в `docs/adr/`.
- Проверить локальные ADR в `boundaries/<context>/docs/adr/`.
- Прочитать `boundaries/README.md` и README затрагиваемых контекстов.

Отсутствие glossary-файлов не является ошибкой: они создаются по мере разрешения доменных терминов.

## Структура

- `GLOSSARY-MAP.md` — карта glossary-файлов bounded contexts.
- `docs/adr/` — общесистемные архитектурные решения.
- `boundaries/<context>/GLOSSARY.md` — язык конкретного контекста.
- `boundaries/<context>/docs/adr/` — архитектурные решения конкретного контекста.

## Правила

Использовать термины из glossary без замены синонимами. Если нужного понятия нет, проверить, не вводится ли лишний термин, либо отметить пробел для `domain-modeling`.

Если предлагаемое изменение противоречит ADR, явно указать конфликт и соответствующий ADR.
