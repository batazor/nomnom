# Issue Tracker

Задачи проекта ведутся в Linear workspace [`bestnomnom`](https://linear.app/bestnomnom).

Список проектов: https://linear.app/bestnomnom/projects/all

При создании задачи:

- выбирать проект по затрагиваемой области;
- не предполагать названия Linear statuses — использовать актуальный workflow выбранной команды;
- применять triage-labels согласно `docs/agents/triage-labels.md`;
- сохранять связи между родительскими, дочерними и блокирующими задачами;
- не считать pull requests отдельным источником входящих задач.

Skills `to-spec`, `to-tickets` и `triage` должны работать с Linear. Если интеграция Linear недоступна, подготовить содержимое задачи и запросить у пользователя способ публикации.
