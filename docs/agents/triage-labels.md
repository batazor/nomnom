# Triage Labels

| Роль в mattpocock/skills | Label в Linear | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется оценка maintainer |
| `needs-info` | `needs-info` | Ожидается дополнительная информация |
| `ready-for-agent` | `ready-for-agent` | Задача полностью определена и готова для агента |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда skill упоминает каноническую triage-роль, используется соответствующий Linear label из таблицы.
